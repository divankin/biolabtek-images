# machinio-photos branch

Full-size listing photos pulled from Machinio (i.machineryhost.com) so label details can be read for the BioLabTek Shopify import.

- `urls.tsv`: Machinio ID, image position, source URL
- `photos/<machinio_id>/<position>.jpg`: downloaded by the workflow on push
- `failed.txt`: any URLs that did not download

This branch is separate from `main` and can be deleted once the listings are filled.
